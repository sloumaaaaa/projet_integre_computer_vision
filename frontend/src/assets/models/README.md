# Assets Directory

## How to Add 3D Models

1. Download GLB/GLTF animal models from:
   - Sketchfab: https://sketchfab.com/
   - Poly Haven: https://polyhaven.com/
   - CGTrader: https://www.cgtrader.com/free-3d-models

2. Place GLB files here with these exact names:
   - elephant.glb
   - lion.glb
   - tiger.glb
   - wolf.glb
   - pig.glb

3. For best AR experience:
   - Keep models under 10MB
   - Use GLB format (not GLTF with separate files)
   - Ensure models are properly oriented (facing forward)
   - Test on mobile for AR compatibility

## Model Requirements

- **Format**: GLB (binary GLTF)
- **Size**: < 10MB for AR
- **Textures**: Embedded in GLB
- **Orientation**: Y-up, facing +Z
- **Scale**: Real-world proportions work best for AR

## Example Free Models

### Elephant
- Search "elephant low poly" on Sketchfab
- Filter: Downloadable, Free license
- Download format: GLB

### Lion
- Search "lion rigged" or "lion animated"
- Choose models with CC-BY or CC0 license

### Tiger
- Similar to lion search
- Look for "tiger 3d model free"

### Wolf
- Search "wolf low poly" for better performance
- Downloadable GLB format

### Pig
- "pig cartoon" or "pig low poly"
- Simpler models work well
