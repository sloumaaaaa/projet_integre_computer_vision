┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔧 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

   ❌ No detection?        → Lower threshold, try different image
   ❌ Backend error?       → Check Flask is running (port 5000)
   ❌ Progress not saved?  → Enable localStorage, avoid incognito mode
   ❌ Can't upload?        → Check file is image format (jpg, png)
